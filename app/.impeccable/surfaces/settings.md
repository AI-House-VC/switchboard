## Direction contract
THESIS: A control panel for consent. Each channel's single segmented choice (Off / Read only / Read & write) is the whole product; everything else exists to make that choice safe. Refuses the dashboard default (stat tiles, charts, counts as heroes).
OWN-WORLD: System Settings: NavigationSplitView sidebar with coloured rounded-square icon tiles, grouped Form sections, system font, semantic colours only (green ok, orange attention, red destructive), SF Symbols, one accent (system). Custom template menu-bar glyph: three jacks patched to one.
STORY: The user sees what each bot can reach, fixes what is blocking, and trusts that switching off deletes the copy.
FIRST VIEWPORT: First run: sidebar with "Get Started" selected; content is a short welcome line and a four-step checklist (Full Disk Access → Choose channels → Sign in to LinkedIn → Connect your bots), each step a row with state and its one action button inline. Configured: Channels page, three rows, each with icon tile, name, status line, segmented picker trailing.
FORM: Native macOS settings (pinned; position 1 of 1). Seed key: none (pinned world, roll skipped).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
